# Website design brief

Andre's review, 22 September 2026: the problem is the whole generic AI landing-page treatment, including the tilted paper asset and its shadow. A functioning page and complete downloads are insufficient. Do not make Andre repeat basic design objections.

Design this as a public resource someone can understand and use. The resource's actual name and purpose lead. Use clear typography, deliberate spacing and useful navigation. No staged stationery, jaunty rotations, drop-shadow document props, invented product mockups, promotional slogans, decorative feature cards or unnecessary animation. Show a real document only where it helps someone inspect it; do not use a pretend document as decoration.

The homepage explains the pack, points to the actual appointment sheet and explains how to begin. Downloads, advocate material and detailed background have their own pages. Labels say what opens and name the format. Keep desktop and phone reading comfortable, keyboard access visible and contrast adequate. Inspect actual browser screenshots before publishing.

Static HTML/CSS remains suitable. No external fonts, analytics, tracking, account, upload or client script is needed. Template v1.0.1 content is unchanged by this web design revision. User testing and the remaining owner interview are still open; do not infer approval from deployment.
