# Project guide

Patient-held Continuity Pack is Andrew Brogan's open-source static patient support kit. Canonical source is this directory. Public files are deployed to /opt/newstation/www/patient-held-continuity-pack/. Build with scripts/build.py. No service restart is needed for static publication.

Keep completed health records out of this project. Only blank templates or clearly fictional demonstrations. Public deployment must use the generated site and dist files, not a directory copy of the working tree. Outreach drafts and operational receipts are private in /home/brodawg/Documents/patient-held-continuity-pack-release-2026-09-22/. Drafts only; Andrew sends mail.
